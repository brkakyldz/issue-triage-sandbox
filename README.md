# issue-triage-sandbox

A sandbox inbox for [`github-issue-triage-agent`](https://github.com/brkakyldz/github-issue-triage-agent),
a Deep Agents agent that triages GitHub issues and asks a human before every write.

The issues here describe **`streaks`**, a fictional command-line habit tracker. There is
no code in this repository: the issues are the test data. They read like a small
open-source project's inbox: bug reports, feature requests, questions, documentation
fixes, three duplicated reports, and one issue that tries to give the triage bot
instructions.

Every label and comment on these issues was proposed by the agent and applied only
after a human approved it.
